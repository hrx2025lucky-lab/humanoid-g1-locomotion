# 课程 PDF 的可读性边界

> 实测于 2026-09-04。**动手做作业不受影响；学原理必须人工看课件。**

## 结论速查

| 类型 | 份数 | 页数 | 提取结果 | 影响 |
|---|---|---|---|---|
| 作业 PDF（实践 1~11） | 12 | 9~32 | ✅ 每页 30~40 行，完整 | TODO 规格、验收标准都能读到 |
| 作业讲解 PDF | 9 | 2~19 | ✅ 完整 | 要点、常见坑都能读到 |
| **课件 PDF（第 2~8 章）** | **7** | **共 425** | ❌ **全部 0 行，完全空白** | **理论推导完全读不到** |

提取好的文本在：

```
~/.copilot/session-state/df3940db-bda3-44cf-8abe-6afb7ca425e6/files/pdftxt/
```

原始 PDF 是深蓝学院的加密格式（文件头 `TSZ#`），`pdftotext` 直接对它无效 ——
上面那批文本是更早的会话用其它方式提取的，**不要重新尝试对 `.pdf` 跑 pdftotext**。

## 三类信息损失

### 1. 课件整份为空（最严重）

七份章节课件共 425 页，提取器能识别页数（第 7 章正确报出 51 页），
但每页 0 行文字。原因是 PPT/Beamer 把文字渲染成了矢量图形轮廓，
不存在可提取的文本层。

**后果**：所有理论讲解、公式推导、架构示意图都读不到。
涉及"课件里怎么说的"这类问题，只能由人翻阅原 PDF。

**所有符号都在，但顺序全乱** —— 能人工还原，不能直接照抄。

### 3. 图片全部丢失

架构图、训练曲线、机器人示意图一张都没有。
作业里凡是"见下图"的地方，文本里都是空的。

## 工作方法

1. **先查提取好的文本**，不要对原 `.pdf` 做任何提取尝试：
   ```bash
   D=~/.copilot/session-state/df3940db-bda3-44cf-8abe-6afb7ca425e6/files/pdftxt
   grep -n "关键词" "$D"/实践8*.txt
   ```
2. **遇到公式**：交叉验证。优先找代码里的参考实现；找不到就请人看原文。
3. **遇到"见下图"或需要理论背景**：直接请人看 PDF，不要猜。
4. 作业要求、TODO 清单、验收标准、文件路径、命令行 —— 这些都是纯文本，可放心使用。
