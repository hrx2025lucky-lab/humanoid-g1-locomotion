# 录像与训练可视化 · 命令速查

> 三套仿真器的参数不一样，容易记混。这里按实践编号给出可直接复制的命令。
>
> 关键前提：**每套实践用的解释器不同**（三套环境互相隔离），
> 用错解释器会报各种 import 错误。每条命令都写明了用哪个。

## 一、录制 play 视频（作业提交材料）

### IsaacLab 系 · 实践 2 / 5 / 8 / 9 / 10

```bash
# 通用形式
cd <该实践的项目根目录>
PYTHONPATH="$PWD/source/unitree_rl_lab:$PWD" \
~/workspace/Roxan_warmup/envs/isaaclab/bin/python scripts/rsl_rl/play.py \
    --task <任务名> \
    --num_envs 1 \
    --video \
    --video_length <一个完整 episode 的步数> \
    --headless
```

**`--video_length` 必须按 episode 实际长度算，不能拍脑袋**：

```
video_length = episode_length_s / step_dt
step_dt      = decimation × sim_dt
```

实践 2 的例子：`episode_length_s=20.0`、`decimation=4`、`sim_dt=0.005`
→ `step_dt = 0.02`，`video_length = 20.0 / 0.02 = 1000`。

> 第一次录像我用了 600，只拍到 60% —— 视频在机器人刚要走出出生平台时就断了。
> 这个坑已经固化进 `scripts/record_play.sh`，实践 2 直接跑那个脚本即可。

**各实践的具体命令**：


### mjlab · 实践 4（蹲姿行走）

mjlab 用 `tyro`，**任务名是位置参数不是 `--task`**，其余选项用中划线：

```bash
cd ~/workspace/Roxan_warmup/shenlan_hw/hw4_mjlab
.venv/bin/python -m mjlab.scripts.play \
    Mjlab-VelocityHeight-Flat-Unitree-G1 \
    --checkpoint-file logs/rsl_rl/g1_velocity_height/<run>/model_latest.pt \
    --video \
    --video-length 1000 \
    --video-width 1280 --video-height 720

# 三组消融的 checkpoint 在：
#   logs/rsl_rl/g1_velocity_height/2026-09-02_20-59-11_ablation_baseline/
#   logs/rsl_rl/g1_velocity_height/2026-09-02_21-52-14_ablation_no_height_rew/
#   logs/rsl_rl/g1_velocity_height/2026-09-02_22-45-34_ablation_blind_actor/
```

**两处易错**：
- 任务名是位置参数：`play <TASK> [OPTIONS]`，写 `--task xxx` 会报错
- 选项用中划线 `--video-length`，IsaacLab 那边是下划线 `--video_length`

查可用任务：`uv run list-envs`
查某任务的全部选项：`.venv/bin/python -m mjlab.scripts.play <TASK> --help`

## 四、常见问题

**Q: 录像时报 `No X display`**
录像本身不需要 display（离屏渲染），加 `--headless` 即可。
只有交互式 viewer 才需要 X。

**Q: 视频只录了一半**
`--video_length` 给小了。按 `episode_length_s / step_dt` 重算。

**Q: 训练时开窗口特别卡**
渲染和物理抢同一张 GPU。看过程时把 `--num_envs` 降到 64 以内。

**Q: `ModuleNotFoundError: No module named 'rsl_rl_amp'`（实践 8）**
`rsl_rl_amp` 没被 pip 安装，靠 cwd 进 `sys.path`。
**必须在项目根目录运行**，换个目录就找不到。

**Q: `ModuleNotFoundError: No module named 'pxr'`**
`pxr` 由 IsaacSim 运行时注入，必须在 `SimulationApp` 启动**之后**才能 import。
裸 python 里 import 一定失败，这不是缺包。
