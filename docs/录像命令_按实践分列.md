# Play 录像命令 · 按实践分列

> 每条都可直接复制。**注意用对解释器**——三套环境互相隔离。
>
> 录像不需要图形界面（离屏渲染），但需要 `--headless`；
> 只有交互式 viewer 才要 X display。

---

## 通用规则：`--video_length` 怎么算

```
video_length = episode_length_s / step_dt
step_dt      = decimation × sim_dt
```

给小了视频会中途断掉。实践 2 我第一次用 600，只拍到 60% ——
机器人刚要走出出生平台视频就没了。

## 视频压缩（提交前）

MuJoCo 离屏渲染出来的 mp4 码率很高，几秒动作能到几百 MB。
提交前压一下：

```bash
ffmpeg -i input.mp4 -vcodec libx264 -crf 28 -preset fast output.mp4
```

`-crf` 越大文件越小（23 是默认，28 已经明显压缩但肉眼差别不大）。

批量压缩一个目录：

```bash
for f in *.mp4; do
    ffmpeg -y -i "$f" -vcodec libx264 -crf 28 -preset fast "compressed_$f"
done
```
