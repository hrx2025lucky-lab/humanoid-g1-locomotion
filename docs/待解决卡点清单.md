## ② 实践 11-训练 — 依赖与现有环境冲突

> **2026-09-04 更正**：本条目原标题是「实践 8 与 实践 11-训练 — 需要 Python 3.12 环境」，
> 把实践 8 一并算进来是错的。实践 8 的作业文档明确写「方案一：复用已有环境（推荐）
> `conda activate env_isaaclab`」，与 Python 3.12 无关。实践 8 已解除阻塞，见 §④。

**现状**：

- 实践 11 的 A/B 部分（深度图流水线 + sim2sim）**已完成**，15/15 验证通过
- 实践 11 的 C 部分（用 InstinctLab 训练）卡在这里

**卡点**（真正的冲突是依赖版本，不是 Python 版本）：

```
instinct_rl/setup.py:  python_requires=">=3.12,<3.13"
                       torch==2.11.0, torchvision==0.26.0, numpy>=2

本机现状：
  envs/isaaclab   Python 3.11.15   torch 2.7.0+cu128   numpy 1.26.0   ← 实践 1~9 全靠它
  系统            Python 3.10.12
```

**实测澄清（2026-09-04）**：

1. `instinctlab` 的 README 写明 IsaacSim **5.1.0** / IsaacLab **2.3.2** / Python **3.11**，
   与 `instinct_rl` 声称的 3.12 自相矛盾。查 PyPI：IsaacSim 5.1.0 的 wheel
   `Requires-Python ==3.11.*`，3.12 只有 IsaacSim 6.0 —— 所以**升级 Python 反而装不上
   课程指定的 IsaacSim 版本**。
2. 因此真正的障碍不是 Python 版本，而是 **torch 2.7 → 2.11、numpy 1.26 → 2.x**：
   直接装进 `envs/isaaclab` 会连带升级，毁掉实践 1~9。
3. 已用 `uv venv --python 3.12 envs/instinct` 建过一个隔离环境（保留着，未装包），
   但按上面第 1 点，正确做法应是**建 Python 3.11 的独立环境**再装 IsaacSim 5.1 + torch 2.11，
   而不是 3.12。完整装一份约 20 GB。

`pip install --dry-run` 直接报：

```
ERROR: Package 'instinct-rl' requires a different Python:
       3.11.15 not in '<3.13,>=3.12'
```

**⚠️ 不能升级 `envs/isaaclab`** —— 那会波及已跑通的实践 1~9，
尤其是按 mujoco 3.12.0 编译的 raycaster 插件。

**要做什么**：另建一套 Python 3.12 环境 + 配套 Isaac Sim。这是独立的搭建工作。

```bash
# 大致步骤（需先装 Python 3.12）
python3.12 -m venv ~/envs/instinct
~/envs/instinct/bin/pip install -e repos/instinct_rl
~/envs/instinct/bin/pip install -e repos/instinctlab/source/instinctlab
# Isaac Sim 需匹配该 Python 版本
```

**已确认可用的材料**（环境好了就能直接训）：

| 项 | 位置 |
|---|---|
| AMP 配置 | `instinctlab/.../tasks/parkour/config/g1/agents/instinct_rl_amp_cfg.py` |
| 跑酷任务配置 | `instinctlab/.../tasks/parkour/config/g1/g1_parkour_target_amp_cfg.py` |
| 参考动作 | `course_code/hiking-in-the-wild_Data&Model/data&model/parkour_motion_reference/` |
| 可部署 checkpoint | 同上的 `checkpoints/`（stand + stair walking） |
