## ① 实践 7 — 缺 SMPL-X 人体模型

**现状**：重定向产物的验证已通过（22/22），但**完整的 SMPL-X → G1 链路跑不了**。

GMR 仓库（`repos/GMR`）本身齐全，含 `unitree_g1` 资产与 4 份 G1 的 IK 配置
（`smplx_to_g1.json` / `bvh_lafan1_to_g1.json` / `fbx_to_g1.json` / `xrobot_to_g1.json`）。

**要什么**：SMPL-X 人体模型，需在官网注册后手工下载（无法自动获取）。

- 地址：https://smpl-x.is.tue.mpg.de/
- 文件：`SMPLX_NEUTRAL.pkl`、`SMPLX_FEMALE.pkl`、`SMPLX_MALE.pkl`

**放哪里**：

```
repos/GMR/assets/body_models/smplx/
    SMPLX_NEUTRAL.pkl
    SMPLX_FEMALE.pkl
    SMPLX_MALE.pkl
```

**⚠️ 装 GMR 之前必读**：GMR 的 `install_requires` 含 `mujoco` / `numpy` / `scipy`，
直接装进 `envs/isaaclab` 可能**升级 mujoco**，而实践 2 的 raycaster 插件是按
**3.12.0** 编译的，版本一变立刻 ABI 不兼容
（症状：`plugin mujoco.sensor.ray_caster not found`）。二选一：

```bash
# 方案 A（推荐）：独立 venv，零风险
python -m venv ~/envs/gmr && ~/envs/gmr/bin/pip install -e repos/GMR

# 方案 B：装进 isaaclab 但不动依赖，再逐个补缺失的包
pip install --no-deps -e repos/GMR
```

**怎么验证解决了**：

```bash
python repos/GMR/scripts/smplx_to_robot.py --smplx_file <某段AMASS动作> --robot unitree_g1
# 然后用已有的验证脚本检查产物
python sim2sim/verify_practice7_motion.py --motion <输出的npz>
```
