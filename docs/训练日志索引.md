## 排障常用命令

```bash
cd ~/humanoid_logs

# 训练进度
grep -oE "Learning iteration [0-9]+/[0-9]+" p5_navigation/p5_baseline.log | tail -1

# 真实任务指标（不要只看 reward / episode_length）
grep -oE "goals_reached: [0-9.]+|error_pos_2d: [0-9.]+" p5_navigation/p5_baseline.log | tail -6

# 探索是否塌缩（实践 5 的关键线索：0.20 → 0.07）
grep -oE "Mean action noise std: [0-9.]+" p5_navigation/p5_baseline.log | tail -5

# 单轮耗时异常（random_arena 曾是基线的 8 倍）
grep -oE "Iteration time: [0-9.]+s" p5_navigation/p5_random_arena.log | tail -3

# 崩溃现场
grep -nE "Traceback|Error|nan|inf" p5_navigation/p5_baseline.log | tail -20
```

一键巡检（自动读上表的默认日志，并给出"学会了没有"的判定）：

```bash
cd "$REPO" && ./scripts/watch_p5.sh
```

## 维护约定

- 新增实践时，在 `scripts/log_paths.sh` 的 `hp_log_subdir()` 里加一行映射即可，其余脚本不用动。
- 日志本身**不入 git**（单文件可达 18 MB），只有本索引和路径定义入库。
- 换机器或换盘：`HP_LOG_DIR=/data/logs ./scripts/run_pipeline.sh`。
