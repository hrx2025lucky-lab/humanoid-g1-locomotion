## 附：这些提取码是怎么拿到的

课程 PDF 里的链接写成 `https://pan.baidu.com/s/xxx?pwd=xxxx` 形式，
而**本机运行环境会把 URL 里的 `pwd=` 参数当作凭据自动脱敏**，
提取出来的文本里只剩 `?******`。

绕过办法是把 PDF 渲染成图片再看：

```bash
pdftoppm -f 6 -l 6 -r 150 -png "实践7：....pdf" /tmp/out
```

ACCAD 这个包一开始就是这么漏掉的 —— 文本里链接后面是一串星号，
没意识到那是第二个必需的下载。后来把全部 22 份作业文本一起
`grep -ohE "pan\.baidu\.com/s/[A-Za-z0-9_-]+"` 扫了一遍，才确认总共 5 个包。
