**路径依据**（不是猜的）：

```python

smplx_folder = HERE / ".." / "assets" / "body_models"

# GMR/general_motion_retargeting/utils/smpl.py:16

```

所以**三个 .pkl 必须直接放在 `smplx/` 里**，不要再套一层文件夹。
若网盘里解压出来是 `models/smplx/*.pkl` 这种结构，只取最里层的三个 pkl。
