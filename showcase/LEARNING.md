# 从原理读到每个实践

学习安排：先读RL算法原理笔记，再读对应实践。实践文档按“任务与输入输出 → 关键代码 → 本篇奖励和重要参数 → 算例 → 行为证据”组织，避免只给结论或参数清单。

每个有训练的实践都要回答：想要什么行为，实际读取什么量，公式为什么这样写，参数过强或过弱有什么代价，最终用什么独立指标验收。预训练部署和GMR几何求解分别讲控制参数与优化代价，不编造未进行的PPO实验。

| 实践 | 奖励/重要参数重点 |
|---|---|
| 1 | 速度误差、权重与宽度、动作平滑；控制频率和PPO采样 |
| 2 | 相对地面高度、抬脚与单脚支撑门控；扫描有效性 |
| 3 | 增量动作、PD、关节顺序和历史；本实践不新训策略 |
| 4 | 高度指令、观测和奖励闭环；课程步数与消融 |
| 5 | 进度/距离/成功/障碍；高低层时钟与冻结低层 |
| 6 | 环境奖励与蒸馏损失；Action/KL系数和退火计数 |
| 7 | IK位置/朝向代价、阻尼、迭代、四元数和fps |
| 8 | 任务与风格反馈、判别器更新；完整走跑动作数据 |
| 9 | 全局/相对身体/关节跟踪；自适应采样与列序 |
| 10 | 地形感知继承的跟踪奖励；参考帧率与控制时间轴 |
| 11 | 任务/接触/风格目标；深度输入和跨仿真器接口 |
