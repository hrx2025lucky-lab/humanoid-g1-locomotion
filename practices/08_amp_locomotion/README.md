# 08 · AMP拟人运动与速度跟踪

Isaac Lab · PPO · AMP · G1 29DoF

将速度跟踪和AMP风格奖励结合，提高转向跟踪权重，并用统一的停止、前进、左右转和加减速命令选择模型。**自然步态仍未通过验证**，首页动态预览保持撤下；以下保留阶段记录，全部结果来自仿真。

## 最新一轮：拖腿问题已解决，整体自然性仍未通过

定位到两个此前未被发现的原因，并用冻结的单因素实验逐个检验。

**原因一：AMP判别器在训练中全程被暂停。** 框架的饱和保护在“策略分数≤−0.7且专家分数≥0.7”时停止判别器更新，而判别器自身的训练目标是±0.8——它到不了目标就先进入暂停带，暂停后分数不再变化，形成自锁。实测500次更新中500次判定饱和，判别器只发生4次优化步。风格奖励因此冻结在上限的24.8%。任务奖励里没有任何鼓励抬脚的项，自然步态本应由风格奖励提供，信号冻结就只剩速度跟踪塑造动作。

解除该暂停后（单因素，其余条件不变），判别器优化步数由4升至2000，0.5m/s前进时“两脚摆腿抬升的较小值”从上一轮最好的2.13cm提高到5.01cm（门槛2.5cm），并首次出现两个模型在该场景通过全部数值门槛。**拖腿与左右不协调已解决。**

**原因二：镜像损失的系数量级失衡。** 镜像误差项数值约为PPO主目标的96倍，系数取1.0时梯度被对称性目标主导，20秒航向变化一度达到310°。改用尺度匹配的0.02与0.10后，对称性改善保留，航向恢复正常。

**仍未通过的两项：**

- **手臂几乎不摆动。** 连续20秒正面画面中两臂全程张开、肘部固定弯曲，看不到与腿部反相的自然摆臂。肩关节俯仰活动范围只有专家走路的9%—16%，同一对比下髋关节为36%—62%，手臂欠缺远大于腿部。原始材料明确要求观察自然摆臂，此条未达到。
- **0.3m/s慢走未通过，原因是参考数据缺口。** 实际加载的四段参考中最慢的持续行走是0.86m/s；落在0.2—0.4m/s的参考帧只占4.2%，且全部来自起步加速瞬态。扩大到全部9段可用素材，0.2—0.45m/s的最长连续片段只有0.40秒。AMP只能把策略推向判别器见过的动作，因此这一项需要补充持续慢走的参考动作，不能靠调参解决。

**验收结论：不批准作为自然步态展示，本轮不发布新的步态视频。** 数值通过的候选已单独重新评估并做过完整正面／侧面人工复核，判定保留为未通过。

**评估方法的限制：** 评估套件在给定模型顺序下完全确定（同一权重排在同一位置时轨迹逐位一致），但仿真器在模型之间保留内部状态，同一权重排在不同位置时20秒航向可差约5°。因此最终候选均单独排在第一位重新评估后才进入人工复核。

## 左右步态检查

在0.5m/s指令的同一段20秒回放中，排除最初2秒后，左脚支撑占比66.0%，右脚80.2%；典型无接触时间分别为0.20秒与0.12秒。两条腿均有迈步，但右脚支撑更久、摆动更短促。典型摆动脚踝抬高量约3.86厘米与1.90厘米，关节活动也明显不对称。身体速度的5%—95%分位约为0.298—0.560m/s。

这些原始状态解释了可见的顿挫和不协调。脚踝抬高量是相对前后接触边界的诊断值，不是精确足底间隙；脚踝移动也可能包含脚掌滚动，不能直接全部计为滑步。此前仅按速度、航向和是否跌倒筛选，未充分覆盖步态质量，不能称为理想行走效果。

## 已完成的改进

- 保持模型恢复起点、专家库和4096环境容量一致，将角速度跟踪奖励权重从0.5提高到2.0；保留AMP任务混合权重0.5与风格尺度5。
- 完成241次同预算比较和500次候选续训，统一检查14个新旧模型；所有候选及未改善结果保留在[完整结果](results.json)中。
- 按本轮预先设定的速度与航向阈值，标称初态下通过3/9项：停止、慢走 0.3、前进 0.5。这些是本项目的筛选阈值。
- 另有7/9个场景持续20秒未触发物理终止；改变初始朝向后，此项记录为14/18。未摔倒的数量不等于命令跟踪通过数量。
