# 08 · AMP拟人运动：训练与比较

提高转向速度跟踪奖励的权重，在保留AMP风格目标的同时改善左右命令响应。配置改动见[amp_tracking_tuning.py](amp_tracking_tuning.py)，实际训练量见[record.json](record.json)。

- 单因素对照：同一个5759恢复起点，4096环境，每轮24步，各新增241次更新；角速度奖励权重0.5与2.0，尺度参数均为0.5rad/s。
- 候选继续新增500次更新，保持奖励配置不变，每100次保存。重新启动会重建环境、课程和回放缓存，因此不能把完整741次路径当作一次不中断的严格配对训练。
- 训练种子20260912，评估种子42；控制周期20ms，物理周期5ms。AMP任务混合权重0.5、风格尺度5，专家库与并行容量不变。
- 当前展示采用**yaw2_6200**，从新旧模型的统一回放中选择；模型编号和是否最新不决定展示优先级。

| 数据 | 内容 |

速度误差从原生物理执行记录复算，统计在首次终止处截断；恒定命令的速度均值与RMSE取2秒之后，航向变化覆盖完整已运行时段。接触期足端速度是诊断量，不能单独作为脚底完全无滑动的证明。

此目录保存配置改动与实验记录，依赖AMP框架、已核对的参考初始化接口和专家运动库；不打包完整框架或数据，也不将配置片段描述为独立训练程序。来源见[框架与资料](../../../REFERENCES.md)。
