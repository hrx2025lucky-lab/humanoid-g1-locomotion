# 07 · 人体到G1的运动重定向

GMR · SMPL-X · 逆运动学

从人体运动数据生成G1参考动作，完成坐标、四元数、关节顺序、帧率和运动库格式转换。

## 已实现

- 执行人体动作到机器人运动的GMR重定向，覆盖行走、加速跑和右转。
- 核对世界/根节点坐标、wxyz四元数以及关节与身体顺序。
- 完成运动学回放、人形对照与AMP加载链路检查。

## 实验结果

已有三类候选动作与人体/G1对照视频，可用于检查动作映射和数据接口。

**验证范围：**运动学回放直接驱动姿态，不证明力矩控制下的动态平衡；短片段和脚地关系仍有质量限制。
