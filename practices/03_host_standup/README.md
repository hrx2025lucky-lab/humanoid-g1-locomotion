# 03 · HoST起身与增量动作部署

HoST · PD · MuJoCo

在23关节G1模型上部署HoST预训练起身策略，复现增量目标角与历史观测接口。

## 已实现

- 实现增量动作到关节目标的映射，并与PD控制连接。
- 核对456维历史观测、23关节顺序及仿真时钟。
- 完成默认仰躺初态下的60秒回放与状态检查。

## 实验结果

默认仰躺场景中已复现起身并保持站立的部署链路，附完整60秒视频。

**验证范围：**使用已有预训练策略；未进行HoST自主训练，未验证任意跌倒姿态恢复。
