# 05 · 分层强化学习导航

Isaac Lab · 高层PPO · 冻结低层策略

以高层速度决策连接冻结的低层行走策略，对固定布局和随机布局模型进行相同预算的交叉评估。

## 已实现

- 核对高层3维速度输出、低层动作映射和历史缓存。
- 构建可复读的障碍、目标与初态场景清单。
- 完成2模型×2场景族×3种子×128局，共1,536局、768组配对。
- 完成128并行环境加载与10个高层步检查，记录1,280条状态，新增训练为0。

## 实验结果

固定布局场景中两模型均为375/384成功；随机场景中固定布局训练模型376/384、随机布局训练模型374/384。

**验证范围：**未获得随机布局训练提高到达率的证据；成功条件含距离缓存边界。固定布局951→3000更新尚未补齐，128环境短步进不代表4096环境或完整导航验证。
