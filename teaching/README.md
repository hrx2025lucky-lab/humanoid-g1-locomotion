### "讲一个你遇到的最难的 bug"

**首选**：[实践 5 §5 坑 1](05_分层强化学习导航.md) —— `update_history` 默认 False
导致低层观测的 5 帧历史退化成当前帧重复 5 次。

这个故事好在：
- **反直觉**：表面指标全绿（episode 满值、摔倒率 0.6%），但到达率恒为 0
- **有方法**：oracle 测试把"算法学不会"和"任务本身有问题"彻底切开
- **有结果**：0% → 97.5%
- **可迁移**：不改变形状、不改变量级、不报错的静默失效怎么找

## 反复出现的几类坑

这些跨实践重复出现，值得单独记：

**1. 约定不一致，且不会报错**
- 四元数 wxyz / xyzw（实践 3、7）
- 关节顺序 SDK / policy（实践 11）
- 两套 offset：射线起点 vs 观测基准（实践 2、10）

**2. off-by-one**
- 扫描格点含两端边界：`size/res + 1`
  - 实践 2：1.6/0.1 → 17×11 = 187
  - 实践 5：5.0/0.12 → 42×26 = 1092
  - 实践 10：1.6/0.1 → 17×17 = 289
- 采样帧上界用 T 而非 T−1（实践 9）

**3. 指标本身有问题**
- `goals_reached` 在 SingleGoal 模式下恒为 0（实践 5）
- 有课程学习时 reward 下降不代表退化（实践 2）
- 有上界的比率指标，用绝对斜率判收敛会高估剩余空间（实践 5）

**4. 默认参数不是为你的用法设计的**
- `update_history=False`（实践 5）
- `smplx.create(ext='npz')` 而课程发的是 pkl（实践 7）
- `compute_group()` 的历史缓冲（实践 5）
